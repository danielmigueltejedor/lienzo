## Español

Lienzo es un editor de imágenes nativo escrito en Rust para trabajar por capas, sin cuentas ni nube.

### Qué incluye
- **Edición por capas:** capas, máscaras, capas de ajuste, objetos inteligentes, selecciones, trazados, texto y pinceles.
- **Documentos de Photoshop:** abre y guarda PSD y PSB, además de su formato propio y los formatos de imagen habituales.
- **Diseño de Nodalia:** islas redondeadas, el acento de Lienzo, tipografías Sora e Inter y controles de ventana redondos (o los del escritorio), con tema claro y oscuro según el sistema.
- **Todo es un comando:** cada acción se puede automatizar y ejecutar desde la línea de comandos.

## English

Lienzo is a native image editor written in Rust for working in layers, with no account and no cloud.

### What's in it
- **Layer-based editing:** layers, masks, adjustment layers, smart objects, selections, paths, type and brushes.
- **Photoshop documents:** opens and saves PSD and PSB, plus its own format and the usual image formats.
- **Nodalia Design:** rounded islands, Lienzo's accent, Sora and Inter, round window controls (or the desktop's own), light and dark following the system.
- **Every action is a command,** so it can be scripted and driven from the command line.
