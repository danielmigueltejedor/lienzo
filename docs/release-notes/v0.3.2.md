Lienzo 0.3.2: el actualizador integrado vuelve a instalar las versiones nuevas en macOS y la pantalla inicial es clara en el modo claro.
*Lienzo 0.3.2: the in-app updater installs new versions on macOS again and the Home screen is light in light mode.*

> [!IMPORTANT]
> Lienzo está en una fase temprana. Guarda una copia de los documentos importantes.
> *Lienzo is at an early stage. Keep a copy of documents that matter.*

## Español

### Novedades
- **Las actualizaciones desde la app funcionan en macOS:** al pulsar «Reiniciar» tras descargar una versión, la instalación acababa con «No se pudo instalar la actualización: has an invalid code signature». La comprobación de la firma rechazaba los metadatos de Finder que lleva todo archivo de una imagen de disco, aunque la app estaba bien firmada. Ahora se verifica el sello de la app (firma y todos sus archivos) sin ese criterio de más, y el error, si aparece, dice qué app falla y por qué.
- **Pantalla inicial clara en el modo claro:** la pantalla de inicio se dibujaba como un lienzo gris dentro de un marco claro. Ahora es una isla clara como el resto de la interfaz.

### Notas
- **Instala esta versión a mano una vez:** Lienzo 0.3.0 y 0.3.1 llevan el actualizador antiguo y no pueden actualizarse a sí mismas en macOS. Descarga el DMG, arrastra Lienzo a Aplicaciones y, a partir de esta versión, las siguientes se instalan desde la propia app.
- Si macOS bloquea la app la primera vez, haz clic derecho en Lienzo dentro de Aplicaciones, elige **Abrir** y confirma. El DMG no está firmado ni notarizado.
- En Linux y Windows no cambia nada: el actualizador ya funcionaba.

## English

### What's new
- **In-app updates work on macOS:** after downloading a version and pressing "Restart", the install ended with "Could not install the update: has an invalid code signature". The signature check rejected the Finder metadata every file from a disk image carries, even though the app was correctly signed. The app's seal (signature and every sealed file) is now verified without that extra rule, and an error, if one appears, names the app and the reason.
- **A light Home screen in light mode:** the Home screen was drawn as a grey canvas inside a light frame. It is now a light island like the rest of the interface.

### Notes
- **Install this version by hand once:** Lienzo 0.3.0 and 0.3.1 ship the old updater and cannot update themselves on macOS. Download the DMG and drag Lienzo to Applications; from this version on, later ones install from within the app.
- If macOS blocks the app the first time, right-click Lienzo in Applications, choose **Open**, and confirm. The DMG is not signed or notarized.
- Nothing changes on Linux and Windows: the updater already worked there.
