## Español

### Novedades
- **macOS:** instalador DMG universal (Apple Silicon e Intel) y la línea de comandos `lienzo-cli` aparte.
- **Windows:** instalador MSI y versión portable para x64.
- **Controles de ventana nativos en macOS y Windows;** los controles redondos de Nodalia quedan para Linux.
- **Un solo lenguaje de diseño de Nodalia** en toda la app, y el tema claro u oscuro se elige solo en Preferencias.
- **Icono redondo** con los colores por defecto de Lienzo.

### Notas
- Si macOS bloquea la app la primera vez, haz clic derecho en Lienzo dentro de Aplicaciones, elige **Abrir** y confirma.

## English

### What's new
- **macOS:** a universal DMG installer (Apple Silicon and Intel), with the `lienzo-cli` command line separately.
- **Windows:** an MSI installer and a portable build for x64.
- **Native window controls on macOS and Windows;** Nodalia's round controls are for Linux.
- **One Nodalia design language** across the app, and the light or dark theme is chosen only in Preferences.
- **A round icon** in Lienzo's default colours.

### Notes
- If macOS blocks the app the first time, right-click Lienzo in Applications, choose **Open**, and confirm.
