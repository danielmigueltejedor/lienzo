*Lienzo 0.3.3: Lienzo documents have an extension of their own, `.lienzo`, and those saved with earlier versions still open.*

> [!IMPORTANT]
> Lienzo está en una fase temprana. Guarda una copia de los documentos importantes.
> *Lienzo is at an early stage. Keep a copy of documents that matter.*

## Español

### Novedades
- **Extensión propia `.lienzo`:** el formato nativo, el que guarda todo sin pérdidas (capas, máscaras, estilos, objetos inteligentes), se guarda ahora como `.lienzo`. Al elegir «Lienzo» en Guardar como, al convertir un documento de Paint.NET o al empaquetar un documento con Archivo › Empaquetar, el archivo nuevo termina en `.lienzo`.
- **Los documentos anteriores se siguen abriendo:** los guardados con versiones anteriores, con la extensión que usaban entonces, abren igual que antes, desde Archivo › Abrir, arrastrándolos o con doble clic. Archivo › Guardar los escribe en su sitio con su nombre de siempre; Guardar como propone el mismo nombre con `.lienzo`. El contenido del archivo no cambia, solo su extensión.
- **Asociaciones de archivo:** Linux (tipo MIME `application/x-lienzo`), macOS y Windows reconocen la extensión nueva y la anterior como documentos de Lienzo y los abren con Lienzo.

### Notas
- Un documento nuevo sigue proponiéndose como PSD en Guardar como, como hasta ahora; elige «Lienzo» para guardarlo en el formato nativo.
- Si macOS bloquea la app la primera vez, haz clic derecho en Lienzo dentro de Aplicaciones, elige **Abrir** y confirma. El DMG no está firmado ni notarizado.

## English

### What's new
- **An extension of its own, `.lienzo`:** the native format, the one that keeps everything losslessly (layers, masks, styles, smart objects), is now saved as `.lienzo`. Choosing "Lienzo" in Save As, converting a Paint.NET document or packaging a document with File › Package gives a new file ending in `.lienzo`.
- **Earlier documents still open:** those saved with earlier versions, under the extension they used then, open as before, from File › Open, by dragging them in or by double-clicking. File › Save writes them back in place under their usual name; Save As offers the same name with `.lienzo`. The file's contents don't change, only its extension.
- **File associations:** Linux (MIME type `application/x-lienzo`), macOS and Windows recognise the new extension and the earlier one as Lienzo documents and open them with Lienzo.

### Notes
- A new document is still offered as PSD in Save As, as before; pick "Lienzo" to save it in the native format.
- If macOS blocks the app the first time, right-click Lienzo in Applications, choose **Open**, and confirm. The DMG is not signed or notarized.
