Lienzo portable mode

While this file sits next to lienzo.exe, Lienzo keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the LienzoData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move Lienzo with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Lienzo for settings
and %LOCALAPPDATA%\Lienzo\Recovery for crash-recovery autosaves. If LienzoData can't be
written (for example on a read-only drive), Lienzo says so and uses those folders instead.
